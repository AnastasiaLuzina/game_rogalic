----Описание проекта----

Текстовый roguelike-квест в стиле "подземелий тьмы" с элементами RPG:
Исследуйте процедурно генерируемые подземелья
Сражайтесь с монстрами (нежить, призраки, темные маги)
Собирайте оружие и зелья (мечи, луки, ледяные посохи)

Управляйте инвентарем (8 слотов, экипировка оружия)

🛠 Технологии
Язык: Python 3.10+

Библиотеки:
curses - отрисовка интерфейса
colorama - цветной текст
random - процедурная генерация

Архитектура: ООП с разделением на системы (комбат, инвентарь, рендер)

Клавиша	Действие
WASD	Движение героя
F	Подобрать предмет
TAB	Открыть/закрыть инвентарь
E	Использовать предмет
R	Выбросить предмет
U	Снять оружие
Q	Выход из игры

🧩 Особенности реализации
🔥 Комбат-система
Три типа атак: обычная, двойной удар (меч), крит. выстрел (лук)

Эффекты статусов: заморозка (посох), яд (зелья)

Шанс побега: 50%

🗺 Генерация карты
Алгоритм MST (Minimum Spanning Tree) для соединения комнат

Динамический радиус обзора (FOV)

Запоминание исследованных областей

Инвентарь: Слотов 8 + Экипированное оружие ("в руках")

📊 Статистика проекта
Количество классов: 15
Строк кода: ~1200
Типов врагов: 3 (Нежить, Призрак, Темный маг)
Типов предметов: 5 (Меч, Лук, Посох, Зелья)
